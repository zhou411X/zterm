zTerm

启动：在应用菜单搜索“zTerm”。
命令行：~/.local/bin/zterm
旧命令 ssh-workbench 仍可使用，原有服务器列表和外观配置继续保留。

左侧服务器栏底部依次为“添加服务器”“编辑服务器”“复制服务器”“移除服务器”；标题栏右上角“设置”包含“快捷键”“外观设置”“订阅额度”“诊断日志”“关于 zTerm”。
“关于 zTerm”显示当前运行版本，打开期间终端仍可操作；升级后重启应用才能加载新版本。
点击“添加服务器”填写显示别名、IP 地址、用户名、密码和端口（默认 22）。
添加窗口可独立移动和缩放，填写期间主终端仍可操作；重复点击会唤回已有窗口。
IP 支持 IPv4/IPv6；用户名必填；显示别名留空时使用 IP，别名显示在侧栏和窗口标题。
若 ~/.bashrc 的静态 SSH 别名中只有一个登录用户名，会自动预填，可自行修改。
密码留空使用已有密钥登录；填写后保存到系统钥匙环，不写入 servers.json 或 SSH 参数。
密码保存需要可用的 Secret Service（如 GNOME Keyring），钥匙环锁定时按系统提示解锁。
新增服务器的 IP、用户名和端口以表单为准，密钥和跳板等其他设置仍由 OpenSSH 管理。
旧版本已保存的服务器继续保留，按别名或目标 IP 匹配 ~/.bashrc 中的直接 SSH 命令，
优先采用其中指定的用户和选项；不执行 .bashrc、变量展开或复杂 shell 命令。
终端连接和 Codex 后台查询共用相同的连接配置。
所有 SSH 连接默认带 ServerAliveInterval=60、ServerAliveCountMax=3，每隔约 60 秒发送保活信号，
避免 NAT 或防火墙静默断开；.bashrc 别名中显式指定的保活参数优先。
选中左侧服务器后可点击底部“编辑服务器”修改显示别名、IP、用户名、密码和端口（也可右键）。
“复制服务器”用同一 IP/用户名/端口/已存密码快速新建副本，无需重新输入密码；副本别名自动加“ 副本”后缀。
编辑窗口独立移动；密码不会回显，留空保留原密码，勾选“清除已保存密码”可改用密钥登录。
旧 IP/别名条目按原 SSH 配置预填；保存不修改 ~/.bashrc 或 ~/.ssh/config。
别名立即更新；连接信息用于新会话或重新连接，现有连接和侧栏顺序保持不变。
点击左侧服务器建立第一个会话；最后一个会话标签紧邻的“+”创建独立连接。
左侧服务器可拖拽排序：拖到目标行上半部/下半部，分别插入其前/后，指示线标出落点。
顺序自动保存，重启后保留；“本地终端”固定在顶部。排序保留已有连接和会话标签。
标签按 [1] 活动内容、[2] 活动内容、+ 顺序排列；标签过多时可横向滚动。
每个标签固定宽度 240（原来的 1.5 倍），长标题末尾省略，悬停显示完整内容；“×”固定在右侧。
活动内容来自 shell/程序上报的终端标题，无标题时显示启动程序名（如 bash、ssh）。
识别到独立 Codex 字样时显示如 [1] [CODEX] Codex · 任务名；/codex 目录及 codex.py 文件不标记。
该标记依据标题，不扫描远端进程；程序未上报或 shell 未恢复标题时，活动信息可能缺失或过时。
会话结束时移除 Codex 标记，重连清空旧活动标题。窗口标题仍显示当前服务器 IP 或别名。
编号按从左到右的位置显示，拖拽、新建或关闭后自动连续更新；Alt+1 … 9 对应显示编号。
本地会话标题为“本地终端”，欢迎页标题为“zTerm”。
VTE 0.76 及以上将字符网格贴底对齐，不足一行的余量留在顶部；不改变字号或减少完整字符行。
服务器栏顶部图标可收起/展开服务器栏；收起时左边只保留窄图标栏，现有连接继续运行。
切换服务器时，之前打开的会话会继续运行。标签可拖动排序。
会话结束后保留输出，可以点击“重新连接”。
底部统一为一栏：左侧显示当前服务器及“在线”状态，离线时显示可点击的“重新连接”；
本地会话结束时显示“重新打开”。状态随当前标签切换，悬停可查看退出码或启动失败原因。
侧栏底部或右键服务器 IP/别名 →“移除服务器”可移除连接配置及对应钥匙环密码，不修改 SSH 配置。
右键移除针对所点击的服务器，有活动会话时先确认；未完成的文件任务会阻止移除，其他服务器会话不受影响。
关闭活动会话、服务器或窗口时会提示确认。
重启工作台会保留服务器列表，但不会自动恢复 SSH 连接。

SFTP 文件传输：
文件栏固定在右侧，每次启动默认关闭；拖动分隔线调宽，收起后再展开保留本次窗口的宽度。
选择服务器后点击右侧栏顶部文件夹图标展开，再次点击收起；收起时仅显示图标栏。
也可右键服务器 →“浏览服务器文件”。
右键浏览不会新建终端；首次进入登录目录，可输入路径、双击目录或点“↑”返回上层。
面板宽度可拖动调整；当前窗口记住各服务器目录，不自动跟随终端的 cd。
点击“上传”后，双击单个本地文件即可上传，也可多选后点击“上传”确认。
文件选择/命名窗口不会阻塞终端；确认和取消按钮位于窗口底部，同一目标重复打开会唤回已有窗口。
窗口显示服务器/路径，不同目标或任务分别处理；切换服务器不会改变已打开窗口的传输目标。
“上传目录”选择整个目录，也可把本地文件拖入文件面板。
多选远端文件/目录后点“下载”，再选本地目标目录。支持新建目录、重命名、删除文件或空目录。
“文件 · SFTP”面板底部队列显示进度和平均速度，不占终端高度；可取消/重试，同名文件可覆盖、另存或跳过。
目录任务覆盖前会统一确认，覆盖该任务内全部同名普通文件；文件类型不同不会强行替换。
收起面板同时隐藏队列，传输继续；切换服务器或关闭会话不会取消传输，关闭应用会提示取消未完成任务。
连接使用现有 SSH 配置/密钥/钥匙环；未保存密码时会弹窗询问，不会在终端里输入传输命令。
未知主机需确认，主机密钥不匹配拒绝连接；远端需启用 SFTP，客户端需 python3-paramiko。
任务串行执行、历史仅保留在当前窗口；不支持续传、目录同步或跟随符号链接。
取消/断网可能残留远端 .zterm-*.part 临时文件，任务悬停详情显示路径；不会当作完整目标文件。

诊断日志：
“设置 → 诊断日志”可查看日志路径及当前进程 PID。
默认写入 ~/.local/state/zterm/zterm.log（若设置 XDG_STATE_HOME 则使用该目录）。
主日志自动轮转，最多 4 份、每份约 2 MiB；记录窗口/文件任务状态与异常，不记录密码、终端正文或文件内容。
界面超过 10 秒没有心跳时记录线程栈；启动前设置 ZTERM_LOG_LEVEL=DEBUG 可增加连接阶段记录。
致命错误及手动线程栈保存在同目录 crash.log；新版进程可用 kill -USR1 <PID> 采集线程栈。
旧版进程不支持该信号。crash.log 超过 2 MiB 后在下次启动截断，详细说明见 README。

外观设置：
“字体与配色”和“背景效果”分页显示设置；背景图片与透明度开关在“背景效果”页。
可选择 PNG、JPEG、WebP 背景图片，调整“图片强度”和“图片毛玻璃”（0 为关闭）。
随包附带 zterm-mist-light.png 和 zterm-mist-dark.png，不自动应用。
deb 图片目录：/usr/share/ssh-workbench/backgrounds/；用户级安装：${XDG_DATA_HOME:-~/.local/share}/ssh-workbench/backgrounds/。
“背景不透明度”15%–100%，100% 为不透明；文字与按钮保持清晰，不随背景变淡。
勾选“背景图片同时应用到终端”后图片才用于终端；否则终端背景保留主题色，仍支持透明度。
图片在工作区居中裁剪填充；标题栏为透明主题色。毛玻璃模糊图片，不实时模糊桌面后方的窗口。
透明桌面透视需要合成器支持。图片处理在后台完成，最大 4000 万像素，绘制缓存最长边 2560 像素。
保存图片绝对路径，请保留原图；原图丢失退回主题色，可重新选择或清除。“清除”不删除原图。
预览时背景效果同步到会话；取消恢复保存值，图片处理完成前不能保存。
“界面主题”控制 zTerm 的标题栏、服务器侧栏、会话标签、底栏、菜单和应用对话框。
默认“跟随终端配色”，自动搭配所选终端预设；也可独立选择 30 套配色或“跟随系统外观”。
界面使用协调的背景、层次色和强调色；终端自定义文字/背景色不会改变界面主题。
选择时实时预览界面，“取消”或关闭设置窗口恢复原样，“保存并应用”后重启仍保留。
点击“设置 → 外观设置”，在“字体与字号”中选择已安装的字体、字形和大小。
支持浅黄背景黑字、白底黑字、黑底灰字、黑底白字、黑底绿字、Ubuntu 默认，
配色依据 Ubuntu 24.04 的 GNOME Terminal / Yaru，使用其默认 ANSI 16 色。
保留 Solarized、Gruvbox、PaperColor、Peaksea 各自的 Light / Dark 配色。
新增 Monokai、Ayu Light / Dark、AyuMirage、Breadog、ClawBeige Light / Dark、
DragonBeige、FaultySchematics、NightOwl Light / Dark、RetroTheme、
TokyoNight Light / Dark / Storm 和 VintageLight；合计 30 套，终端与界面均可选择。
Gruvbox、PaperColor、Peaksea 的普通色与亮色采用 Vim 主题的主要语法高亮 RGB。
PaperColor 按截图校正默认 Vim 的注释/语句色槽，并适配 256 色索引 81、121；其他扩展索引不变。
命令程序决定哪些文字使用哪个颜色；共享色槽不能按语法拆开匹配，truecolor 输出不受影响。
新配置默认使用 Ubuntu 默认。经典紫、深色、浅色、深海蓝已移除，旧配置自动兼容迁移，
字体与自定义颜色保留；读取不改写配置文件，在保存外观后写入新主题标识。
也可分别设置文字、背景和光标颜色。来源与适配说明见 THEME_SOURCES.txt。
切换主题会恢复该主题的预设颜色；之后可以继续自定义颜色。
对话框下方实时预览。“保存并应用”同时更新所有会话并保存设置，新会话和重启后均沿用。
外观设置为独立窗口，可单独移动、缩放和最大化；打开时主终端仍可操作。
主窗口和外观设置窗口在 X11 下请求初始居中，之后可自由拖动；Wayland 下由桌面决定位置。
默认使用 GTK 原生显示后端，在 Wayland 桌面上避免强制 XWayland 引入的分数缩放字体模糊。
显式 GDK_BACKEND=x11 可使用 XWayland 请求居中，但分数缩放下文字可能发虚；不改变系统全局设置。
重复打开会唤回已有窗口并保留未保存的预览；关闭主窗口时一起关闭外观设置。
“取消”不改变会话或已保存配置；“恢复默认”先更新预览，保存后才生效。
保存外观会将各会话的临时字体缩放重置为 100%；之后仍可用快捷键缩放。
“终端配色”改变终端内容区；“界面主题”独立控制应用外观。外观配置与服务器列表分别保存。

SSH 连接使用 /usr/bin/ssh，优先使用密钥，保存过密码时再通过 askpass 从钥匙环读取。
保存密码的会话通过独立窗口确认主机或输入密钥口令；没有保存密码时沿用终端交互。
服务器密码仅提供给匹配目标用户名和 IP 的密码提示，不用于跳板机或密钥口令。

别名列表：${XDG_CONFIG_HOME:-~/.config}/ssh-workbench/servers.json
外观配置：${XDG_CONFIG_HOME:-~/.config}/ssh-workbench/appearance.json
程序文件：${XDG_DATA_HOME:-~/.local/share}/ssh-workbench/

订阅额度：
统一底栏中间显示当前机器 Codex 的已用比例和重置时间，切换服务器随之更新。
查询在后台进行，每 5 分钟自动刷新；右侧 ↻ 可手动刷新，悬停查看数据时间。
重置时间使用工作台所在机器的时区；已到重置时间的旧数据标记“待刷新”。
远端需 Python 3.9+，使用密钥/agent，或已存入解锁钥匙环的密码。
请先建立一次终端会话确认主机密钥，后台查询不会弹出登录或解锁提示。
Codex：服务器需安装 codex CLI 并使用订阅账号登录；仅调用官方额度读取接口。
未返回数据、未登录、网络失败均显示具体状态，不将缺失数据显示为 0%。
额度仅覆盖官方提供的 Codex 主额度/次额度，不代表模型专属额度或 API 余额。
工作台不读取或传输 Codex 登录凭据，不会修改远端 CLI 配置。

开发验证：
/usr/bin/python3 -m py_compile app.py model.py credentials.py quota.py test_workbench.py test_quota.py test_credentials.py
/usr/bin/python3 test_credentials.py
/usr/bin/python3 test_quota.py
GDK_BACKEND=x11 xvfb-run -a /usr/bin/python3 test_workbench.py

依赖：python3-gi、gir1.2-gtk-3.0、gir1.2-vte-2.91、gir1.2-secret-1、openssh-client。
保存密码需要桌面钥匙环服务，如 gnome-keyring。

和 applications/local.ssh.Workbench.desktop。别名配置可按需保留。
